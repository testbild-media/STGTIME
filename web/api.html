REST API v1

STGTIME API

All requests and responses use JSON unless noted. Use an authenticated browser session, Authorization: Bearer TOKEN, or x-api-token: TOKEN.

Timer

GET/api/v1/state

Returns timer, display, message, video and system status.

PUT/api/v1/timer

{
  "mode": "countdown",
  "durationMs": 600000,
  "jogMs": 10000,
  "continueNegative": false
}

Every field is optional. Setting a duration stops and resets the timer.

POST/api/v1/timer/action

{ "action": "start" }

Actions: start, stop, toggle, reset.

POST/api/v1/presets/{id}

Loads the preset duration together with its Warning and Critical remaining-time thresholds.

PUT/api/v1/presets

{ "presets": [{ "id": "keynote", "name": "Keynote", "durationMs": 1200000, "thresholdsMs": { "warning": 200000, "critical": 100000 } }] }

Thresholds must satisfy Duration ≥ Warning ≥ Critical. When omitted, Warning defaults to 1/6 and Critical to 1/12 of the duration.

Display and external sources

GET/api/v1/display.png

Returns the exact 64×32 display framebuffer as PNG.

PUT/api/v1/message

{ "visible": true, "text": "PLEASE WRAP UP", "color": "#ffffff" }

PUT/api/v1/video

{ "visible": true, "label": "VIDEO", "remainingMs": 45000, "durationMs": 120000 }

This generic endpoint is intended for Companion-driven vMix, VLC and ProPresenter workflows.

GET / PUT/api/v1/config

{ "display": { "timeZone": "Europe/Berlin" } }

Reads or merges device configuration. The clock accepts IANA time-zone identifiers and applies the selected zone to the Raspberry Pi operating system. Secret hashes and API tokens are never returned.

Software updates

GET/api/v1/update

Checks the latest published release from the official GitHub repository.

GET/api/v1/update/status

Returns the cached release information and current installation status.

POST/api/v1/update/install

{ "password": "current admin password" }

Queues the latest release after verifying its GitHub SHA-256 asset digest.

POST/api/v1/update/upload

Streams an update archive as application/gzip. Supply the administrator password in x-stgtime-admin-password. Maximum size: 128 MiB.

Network and security

GET/api/v1/network

Returns current IPv4 addresses and saved network settings.

POST/api/v1/network/apply

{ "action": "hotspot-on" }

Actions: hotspot-on, hotspot-off, ethernet-dhcp, ethernet-static.

POST/api/v1/auth/login

{ "password": "your password" }

PUT/api/v1/security/password

{ "currentPassword": "current password", "newPassword": "new password" }

The current password is always required. Changing it invalidates all existing browser sessions.

GET/api/v1/health

Unauthenticated liveness endpoint.
